# Product — launch-v2 (2026-09-30)

**Users and jobs.**

* A SwiftUI / Compose / React engineer evaluating whether to share logic at all → the
  landing page's thesis, the live demo, the "why native UI" post.
* A team already on KMP or UniFFI/Crux → the comparison posts with honest trade-offs.
* A developer who wants to try it in 60 seconds → the install block, `undra init`, the
  terminal walkthrough.
* Someone deciding whether the project is alive → the roadmap and the release cadence.

**Scope (in).** The rename to Undra; typography fix; premium redesign; install block
(brew/npm/curl/cargo); docs search and polish; four posts; roadmap page; SEO (meta,
JSON-LD, sitemap, RSS, llms.txt, OG image, IndexNow); live in-browser demo with measured
counters; stress numbers on the landing page; release pipeline for all channels.

**Scope (out).** New framework features; crates.io publishing; Windows; a custom domain;
per-post OG images; Google Search Console verification (founder); a GitHub organisation.

**Success.** The seven criteria in the spec's Section 0. Qualitatively: a native engineer
lands, understands the thesis in ten seconds, sees it running in their tab in thirty, and
can install it in one line.

**Copy rules.** No superlatives without a number next to them. "Measured" beats "fast".
Every competitor mention names the date and links the source. The old name never
appears in user-facing material.
