# Product — v1.1 / v1.2 "the default choice" (2026-10-01)

**Users and jobs.** A platform engineer evaluating Undra for a real app asks: can it do what my
app needs (storage, real-time, background work, every type I model)? will it break my users
(persisted state, lifecycle)? is the dev loop better than what I have (live core on every
platform, devtools, previews, tests)? can I adopt it without rewriting (adoption levels,
migration guides)? can I stay on my UI stack (native, or RN)?

**Success.** By v1.2 the limitations checklist has no "Undra: missing" row; the dev loop is
live on all three platforms with state-preserving reload and devtools; previews and tests run
without a real core; the post with the matrix is published and fact-checked.

**Scope guard.** No shared UI; no hosted services; distribution after v2.
