# undra-meta

The schema data model for [Undra](https://github.com/shreypdev/undra): the one description of a core's public surface from which every language's bindings are derived (constitution rule R1).

`undra-meta` defines:

* `TypeRef`, the type system (`Option`, `Vec`, `Map`, `Named`, `Result`, ...), with the JSON shape `{"kind": "option", "of": {...}}`;
* the owned definitions `Schema`, `RecordDef`, `EnumDef`, `ObjectDef`, `MethodDef`, `StoreDef`, `PortDef`, `QueryDef`, ... (`Serialize`/`Deserialize`);
* `'static`, const-constructible mirrors (`TypeRefMeta`, `RecordMeta`, `ObjectMeta`, ...) that `undra-macros` emits into `static`s, plus `From<&XMeta> for XDef`;
* registration through `inventory` (`Registration`, `collect_schema`, `registrations`);
* the stable identifiers in `ids` (`fnv1a32`, `fnv1a64`, `type_id`, `method_id`, `function_id`, `port_id`, `query_id`, ...), all `const fn`;
* the canonical JSON and 64-bit schema hash (`Schema::canonical_json`, `Schema::hash`) used for the load-time compatibility check;
* `Schema::validate`, the whole-schema rules (unique names, resolvable references, `Result`/`Stream`/`Lazy` placement, map keys, stores need a constructor).

It has no `unsafe` code and depends only on `serde`, `serde_json` and `inventory`.

## Example

```rust
use undra_meta::{
    FieldMeta, ObjectMeta, MethodMeta, ParamMeta, Registration, RecordMeta, Schema, TypeRefMeta,
    DispatchCall, DispatchOutcome, collect_schema, ids,
};
use std::any::Any;

// 1. What the macros emit: `'static` metadata built from constants.
static TODO: RecordMeta = RecordMeta {
    name: "Todo",
    type_id: ids::type_id("Todo"),
    fields: &[
        FieldMeta { name: "id", ty: TypeRefMeta::Uuid, default: false, docs: "" },
        FieldMeta {
            name: "due",
            ty: TypeRefMeta::Option(&TypeRefMeta::Timestamp),
            default: true,
            docs: "When it is due.",
        },
    ],
    docs: "A todo item.",
};

// Dispatchers are generated by the macros; undra-runtime downcasts the erased
// runtime and result types. Here we only need something to point at.
fn dispatch(_runtime: &dyn Any, _call: DispatchCall<'_>) -> DispatchOutcome {
    DispatchOutcome::new(())
}

static TODOS: ObjectMeta = ObjectMeta {
    name: "Todos",
    type_id: ids::type_id("Todos"),
    constructors: &[MethodMeta {
        name: "new",
        method_id: ids::method_id("Todos", "new"),
        params: &[],
        returns: TypeRefMeta::Named("Todos"),
        is_async: false,
        takes_ctx: false,
        docs: "",
    }],
    methods: &[MethodMeta {
        name: "find",
        method_id: ids::method_id("Todos", "find"),
        params: &[ParamMeta { name: "id", ty: TypeRefMeta::Uuid }],
        returns: TypeRefMeta::Option(&TypeRefMeta::Named("Todo")),
        is_async: false,
        takes_ctx: false,
        docs: "",
    }],
    store: None,
    docs: "",
    dispatch,
};

undra_meta::inventory::submit! { Registration::Record(&TODO) }
undra_meta::inventory::submit! { Registration::Object(&TODOS) }

// 2. Collect everything registered in the process into an owned schema.
let schema: Schema = collect_schema("todo-core");
assert_eq!(schema.validate(), Ok(()));

// 3. Hash it (docs and top-level order do not matter) and ship it as JSON.
let json = schema.to_json_pretty();
let received = Schema::from_json(&json).unwrap();
assert_eq!(received, schema);
assert_eq!(received.hash(), schema.hash());

// 4. Stable ids are just FNV-1a of the names.
assert_eq!(ids::fnv1a32("Calculator.add"), 2_353_348_832);
assert_eq!(ids::fnv1a64(b"undra"), 12_206_477_163_874_244_763);
```

## The schema hash

`Schema::hash()` is `fnv1a64` of `Schema::canonical_json()`: compact `serde_json`, docs excluded, and only the six top-level lists (records, enums, objects, functions, ports, queries). The `crate_name` and `undra_version` labels do not change the wire, so they are not part of the canonical form or the hash.

* Unordered things are sorted by name: the six top-level lists, the constructors and methods of an object, and the methods of a port. Enum variants are sorted by index.
* Ordered things are part of the wire layout and keep their declared order: record fields, variant fields, parameters and signals (a signal id is its index).

Two cores with the same public surface therefore hash identically whatever their doc comments, crate name or source order of unordered items, and any rename, retype or reorder of a wire-relevant item changes the hash.

## Dispatch without runtime types

`ObjectMeta` and `FunctionMeta` carry `dispatch: DispatchFn`, a plain function pointer taking `&dyn Any` (the runtime) and a `DispatchCall`, returning an opaque `DispatchOutcome` (a boxed `dyn Any + Send`). This keeps `undra-meta` free of runtime types: the generated dispatcher downcasts the runtime and boxes an `undra_runtime::DispatchResult`; `undra-runtime` downcasts the outcome back.

## Validation

`Schema::validate()` returns every violation as a `SchemaError` with a stable code from SPEC section 12 (`E0050` duplicate type name, `E0005` misplaced `Result`/`Stream`, `E0006` bad map key, `E0011` store without constructor, `E0001` unresolved type, misplaced `Lazy`, or misplaced `Unit`).

`Unit` is legal only as a return type (alone, or as a component of a returned `Result` or `Stream`) or as a variant with no fields. It is rejected as a record, variant or parameter type, as a signal type, and inside `Option`, `Vec`, map values or `Lazy`, because zero-width items defeat length validation.
