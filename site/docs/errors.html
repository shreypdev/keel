Error codes

Every compile error the macros raise has a stable code, a fixed shape and a fix. The link at the end of each message lands on its code below.

How to read one

A diagnostic says what is wrong, why the rule exists and how to fix it. This one is verbatim from the macro test suite:

text
error[undra::E0004]: trait object `dyn Fn(u32)` cannot cross the boundary
  = note: trait objects have no wire representation and no equivalent in Swift, Kotlin or TypeScript
  = help: use a concrete `#[undra::api]` type or an enum listing the cases you need; callbacks into the platform are ports (`#[undra::port]`)
  = docs: https://shreypdev.github.io/undra/docs/errors.html#E0004

Types and shapes#

E0001 unsupported type in a public position#

unsupported type in a public position (lists the type and the allowed set); includes Lazy<T> (lazy lists are not available in v1), Handle (no schema type; objects cross through constructors), a Result whose error type is not a #[undra::error] enum, and a type used as a value that cannot cross (an Encode/Decode bound that is not met)

What you seeWhyFix
Lazy<Row> is not available in v1: lazy lists cannot be mirrored yeta Lazy<T> signal is a list the platform pages through on demand; the platform runtimes have no API for it yet (SPEC section 17), so no language could observe itexpose the items as a Signal<Vec<T>> (keyed with #[undra(key = "..")] if they have an id) or as a paged method that takes an offset and a limit
&str cannot cross the boundaryreferences have no wire representation; every value crosses by copyuse an owned String
usize cannot cross the boundaryits width differs between platforms (32-bit wasm, 64-bit iOS and Android), so the wire layout would toouse a fixed-width integer such as u32 or u64
Ctx parameter on method touchmethods reach the runtime through the object: Ctx is only injected into constructors, free functions, queries and mutationsstore a Ctx in the object when it is constructed, or use Ctx::current()
Instant cannot cross the boundarymonotonic instants are meaningless outside their processuse Duration for spans and Timestamp for points in time; if Instant is a type of your own, rename it: Undra recognises this name wherever it is written
Handle cannot be used in a public signaturea handle is how the runtime refers to an object instance; the schema has no handle type, because an object crosses the boundary through its constructors, never as a value in a signatureuse the object's own methods from the platform (it holds the handle), or return a record with the data the platform needs; if Handle is a type of your own, rename it: Undra recognises this name wherever it is written

E0002 generic parameter#

generic parameter on a #[undra::api] item

What you seeWhyFix
generic parameter T on Pagethe schema describes concrete types; every target language would need one instantiation per useremove the parameter, and declare one concrete #[undra::api] type per instantiation

E0003 lifetime in a public signature#

lifetime in a public signature

What you seeWhyFix
lifetime 'a on Labeleverything crosses the boundary by value; a borrow cannot outlive the call that made itremove the lifetime parameter and use owned types

E0004 trait object, dyn, impl Trait#

trait object / dyn / Box<dyn Fn>

What you seeWhyFix
trait object dyn Fn(u32) cannot cross the boundarytrait objects have no wire representation and no equivalent in Swift, Kotlin or TypeScriptuse a concrete #[undra::api] type or an enum listing the cases you need; callbacks into the platform are ports (#[undra::port])
impl std::fmt::Display cannot cross the boundaryimpl Trait has no wire representation; the only one the schema understands is impl Stream<Item = T> in a return typeuse a concrete type, or impl Stream<Item = T> for a sequence of values over time
boxed stream Pin<Box<dyn undra::runtime::Stream<Item = u32> + Send>> cannot cross the boundarya stream is described to the platforms as impl Stream<Item = T> in a return type; a boxed or dyn stream has no schema representationreturn impl Stream<Item = T> + Send + 'static (box it inside the function if the branches differ)

E0005 Result / Stream outside return position#

Result or Stream outside return position

What you seeWhyFix
Result<u32, String> cannot be used as a fieldResult<T, E> is how a method reports a typed error; it is only legal as the outermost type of a returnreturn the Result from the method and keep only plain values in fields, parameters and nested types

E0006 map key type not allowed#

map key type not allowed

What you seeWhyFix
f64 cannot be a map keymap keys must be String, an integer, bool or Uuid: those compare and hash identically on every platform (floats and composite keys do not)use one of those key types, or a Vec of records with an explicit key field

E0007 unsupported item shape#

unsupported item shape (a tuple or unit struct, a record without fields, an empty enum, an impl item that is neither a method nor a constructor, a receiver that is not &self, a store that is not a struct with named fields, the reserved field name __undra_cell, #[undra::port] on an inherent impl, #[undra::api] on a method, #[undra::query] or #[undra::mutation] inside an impl block)

What you seeWhyFix
tuple struct Meters cannot be a recordthe schema names every field so the other languages can generate properties; tuple fields have no namesuse named fields: struct Meters { value: f64 }
enum Nothing has no variantsan enum without variants has no values, so it can never be sentadd at least one variant
constructor new is asynca constructor inserts the new object into the object table before it replies, so it must finish synchronouslyconstruct synchronously and start asynchronous work with ctx.spawn(..)
helper is neither a method nor a constructora pub fn in a #[undra::api] impl block must take &self (a method) or return Self / Result<Self, E> (a constructor); the return type is read as written, so an alias such as type R<T> = Result<T, E> is not followedadd &self, make it return Self or spell out Result<Self, E>, or make it private / move it to a free #[undra::api] fn
the receiver self: &Arc<Self> of method by_arc is not supportedthe dispatcher resolves the object from its handle and calls the method with &Type; a receiver such as Arc<Self>, Box<Self> or Pin<&Self> needs a different callwrite &self; clone an Arc of the object inside the method if you need one
unit struct Marker cannot be a recorda record without fields occupies zero bytes on the wire, and zero-width items defeat length validation (SPEC section 3.1): a Vec of them would accept any count from a four-byte messageadd a field, or use an enum with a unit variant if you need a marker

E0008 unknown or misplaced #[undra(..)] attribute or macro argument#

unknown or misplaced #[undra(..)] attribute or macro argument (an unknown key, a value of the wrong kind or a value on a flag, key on a signal that is not a Signal<Vec<T>>, #[cfg] on a public item, an invalid crate = ".." path); a cfg_attr whose attributes are all documentation or lint levels is accepted

What you seeWhyFix
unknown option defualt in #[undra(..)]the options are crate = "path" (items), default (record fields), key = "field" and no_coalesce (store signal fields)remove or correct the option
#[undra(key)] is not valid on a record or variant fieldkey = "field" turns a store's Signal<Vec<T>> into a keyed list that ships patchesremove the option, or move it to where it applies
unknown argument colour for #[undra::api]#[undra::api] accepts: crate = "path", and store on an impl block of a #[undra::store] structremove or correct the argument
default takes no valuedefault switches a behaviour on by being present; there is nothing to set it towrite default alone
key must be a string literal naming a fieldkey takes a string literal naming a field; anything else cannot be read at compile timewrite key = "id"
no_coalesce takes no valueno_coalesce switches a behaviour on by being present; there is nothing to set it towrite no_coalesce alone

Errors and stores#

E0010 invalid #[undra::error] variant#

#[undra::error] variant without #[error(..)], a message with an implicit {} (write {0} or {name}), #[error], #[from] or #[source] on a plain #[undra::api] enum

What you seeWhyFix
variant NotFound has no #[error(..)] messageevery variant of a #[undra::error] enum needs a message, because the platforms show it to users and logsadd #[error("what went wrong")], or #[error(transparent)] to forward to the inner error
invalid message for variant Missing: {1} refers to field 1, but the variant has 1the message is a template over the variant's fieldsuse {0}, {1}, .. for tuple fields and {name} for named fields
#[error(transparent)] on variant Both needs exactly one field, found 2transparent forwards Display and source() to the variant's only fieldgive the variant a single field holding the inner error
#[error] on the variant A belongs to #[undra::error], not #[undra::api]#[error(..)], #[from] and #[source] are the helper attributes of error enums; a plain #[undra::api] enum has no messages, Display or From implschange the enum's attribute to #[undra::error], or remove the helper attribute

Queries and mutations#

E0040 query without key, mutation with stale, or another invalid query argument#

query without key / mutation with stale / a query argument of the wrong kind

What you seeWhyFix
query todos has no keythe cache is addressed by key: two calls share a cached result only if their keys are equaladd key = "todos", with {param} placeholders for the parameters that distinguish results
mutation add_todo has stalestale is how long a cached *read* stays fresh; a mutation writes and caches nothingremove stale; put it on the query the mutation invalidates
{pgae} in key is not a parameter of the functioneach placeholder is replaced by the encoded parameter of that namethe parameters are: page
key must be a string literalkey takes a string literal; anything else cannot be read at compile timewrite key = "todos:{page}"
retry must be a whole numberretry takes a whole number; anything else cannot be read at compile timewrite retry = 3
stale must be a string literal with a unitstale takes a string literal with a unit; anything else cannot be read at compile timewrite stale = "30s"

E0041 query or mutation function with an invalid signature#

query or mutation function with an invalid signature (not async, no ctx: &Ctx first parameter, not returning Result<T, E>, a stream result, self)

What you seeWhyFix
sync_query must be async#[undra::query] functions fetch or write through ports, which are asynchronouswrite async fn
no_ctx must take ctx: &Ctx as its first parameterthe runtime hands every query and mutation a context to reach ports and other queriesadd ctx: &Ctx (or ctx: Ctx) before the other parameters
plain must return Result<T, E>the cache stores the success value and the error separately, and the platforms show bothreturn Result<T, E> where E is a #[undra::error] enum

E0042 query whose success value is () or an Option#

query whose success value is () or an Option (a query caches a value; use a mutation for effects)

What you seeWhyFix
query ping returns ()a query caches the value it returns; a query with nothing to return has nothing to cacheuse #[undra::mutation] for a call that only has effects, or return the data the platform needs
